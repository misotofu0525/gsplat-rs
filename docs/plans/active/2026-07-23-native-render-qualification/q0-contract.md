# Q0 Qualification Contract

## Hypothesis

Comparator and native-advantage claims are useful only when source membership,
SH degree, camera schedule, backing resolution and timing scope are recorded
for both sides.

## Required decision record

- Freeze comparator revision, launch path and any feature/path differences.
- Define retained artifact, image and timing receipts per endpoint, marking
  unavailable fields as unavailable rather than inferred.
- Separate near-contract Exact comparison, Balanced throughput comparison and
  native CPU/SIMD/whole-plan experiments. A missing or inconclusive comparison
  is Rejected/Deferred evidence, not an invitation to tune indefinitely.

Q0 does not publish a performance winner or alter product policy.
